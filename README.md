### [Aureum Island](https://github.com/eduoliveira1504/aureum-island)

A notch for the top of your Windows 10/11 screen: music, focus timer, water

`Python`

**v0.2.0** · [Download](https://github.com/eduoliveira1504/aureum-island/releases)

## How it's built

- **Decisions are written down.** Voice keeps its architecture decisions as
  records in [`docs/decisions`](https://github.com/eduoliveira1504/aureum-voice/tree/main/docs/decisions),
  next to a changelog.
- **Shipped with CI and releases.** Both repos have GitHub Actions workflows,
  and Island has a changelog and tagged
  [releases](https://github.com/eduoliveira1504/aureum-island/releases).
- **Private by design.** Island has no account and no telemetry. Calendar
  links you paste stay in the Windows vault.
- **One person, full stack.** Electron, React and TypeScript on the client.
  FastAPI, PostgreSQL, Redis, MinIO and LiveKit on the backend. Python for
  Island.
